How it works

GitHub App + AI SDK 7
01

Webhook fires

Opening a PR posts a pull_request event to /api/webhook. The HMAC-SHA256 signature is verified, then the route returns 202 Accepted and starts the review fire-and-forget.

02

Agent starts

The agent resolves its provider at request time — the Vercel AI Gateway by default (anthropic/claude-sonnet-4-5), or Google AI Studio when GOOGLE_GENERATIVE_AI_API_KEY is set. No API keys in code.

03

Tool loop

The agent calls fetch_pr_files to read the diff, then read_file_context for surrounding code, up to 10 tool rounds.

04

Inline review

post_review attaches critical, warning, suggestion and praise comments to exact lines, plus a summary body.
